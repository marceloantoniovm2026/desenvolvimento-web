Curso de desenvolvimento web

O repositório tem 21 exemplos separados em pastas de HTML, CSS, JavaScript, Bootstrap e PHP. Cada pasta de aula reúne o código e um texto que explica o que ele faz.

Os arquivos HTML montam a estrutura das páginas, com títulos, textos, links, listas e formulários. O index.html da raiz reúne os links para as aulas e suas explicações.

Os arquivos CSS cuidam da aparência e da posição dos elementos. Os exemplos mostram cores, espaços, bordas, colunas e mudanças de layout conforme a largura da tela.

Os arquivos JavaScript alteram o conteúdo da página. Eles mostram valores de variáveis, classificam notas, contam cliques e guardam uma lista de tarefas no navegador.

Os exemplos de Bootstrap usam classes prontas para montar botões, colunas, cartões e formulários. O componente collapse mostra ou esconde um texto ao receber um clique.

Os arquivos PHP geram HTML no servidor, tratam formulários e acessam o MySQL. O cadastro de alunos permite salvar, listar, editar e excluir registros. A conexão fica em conexao.php, e o schema.sql define o banco e a tabela usados pelo cadastro.
