Aula 02: Grid

O index.html organiza três blocos, com os textos HTML, CSS e JavaScript, usando o sistema de colunas do Bootstrap.

O container limita e centraliza a área. Dentro dele, row agrupa as colunas, e g-3 define o espaço entre elas.

O Bootstrap divide cada linha em doze partes. A classe col-12 faz cada bloco ocupar a linha inteira nas telas menores. A partir da largura média, de 768 pixels, col-md-4 faz cada bloco ocupar quatro dessas partes. Assim, os três ficam lado a lado.

Dentro de cada coluna, border desenha uma borda e p-3 acrescenta espaço interno ao redor do texto.
