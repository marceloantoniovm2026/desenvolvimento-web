Aula 01: Introdução ao Bootstrap

O index.html mostra um título, um parágrafo e um link com aparência de botão. A aparência vem das classes do Bootstrap.

O link no head aponta para bootstrap.min.css, que contém os estilos. A tag script aponta para bootstrap.bundle.min.js, que contém o código dos componentes interativos. Os dois caminhos apontam para a pasta assets.

A classe container centraliza o conteúdo e ajusta sua largura conforme o tamanho da tela. A classe py-4 acrescenta espaço interno na parte de cima e de baixo.

A classe lead dá destaque ao parágrafo. No link, btn aplica o formato de botão e btn-primary usa a cor principal do Bootstrap. Apesar da aparência, o elemento continua sendo um link e leva para a segunda aula.
