Arquivos do Bootstrap

Os exemplos das aulas apontam para dois arquivos nesta pasta: bootstrap.min.css e bootstrap.bundle.min.js. Esses arquivos da biblioteca não estão incluídos no repositório.

O bootstrap.min.css contém os estilos que dão aparência às classes usadas nas páginas, como container, row, btn, card e form-control. A terminação min indica que o conteúdo foi compactado para ocupar menos espaço.

O bootstrap.bundle.min.js contém o JavaScript dos componentes interativos e inclui o Popper, usado por alguns componentes da biblioteca. Na aula de componentes, esse arquivo controla a abertura e o fechamento do collapse.

Sem o CSS, as classes do Bootstrap não mudam a aparência da página. Sem o JavaScript, o botão do collapse não alterna a exibição dos detalhes.
