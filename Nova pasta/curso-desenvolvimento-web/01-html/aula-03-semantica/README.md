Aula 03: Semântica

O index.html monta uma página parecida com um blog. As tags indicam a função de cada parte do conteúdo.

O header é o cabeçalho. Dentro dele, o nav reúne a navegação, e aria-label dá o nome Principal a essa área para tecnologias de acessibilidade.

O link com href="#conteudo" aponta para o elemento que tem id="conteudo". Nesse exemplo, ele leva até o main, que contém a parte principal da página.

O article agrupa o texto sobre HTML. O h2 é o título desse texto, e o p contém o parágrafo. O footer representa o rodapé.
