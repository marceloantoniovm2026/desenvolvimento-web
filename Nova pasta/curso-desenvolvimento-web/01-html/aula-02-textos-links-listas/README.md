Aula 02: Textos, links e listas

O index.html mostra um pequeno plano de estudos. O h1 é o título principal, e o h2 apresenta a parte sobre tecnologias.

O ul cria uma lista sem numeração. Cada li representa um item: HTML, CSS ou JavaScript. O p contém uma frase, e o strong marca essa frase como importante. O navegador costuma mostrar esse trecho em negrito.

A tag a cria o link de volta à primeira aula. O href guarda o caminho do arquivo. Nesse caminho, ../ representa a pasta acima da pasta atual.
