Aula 01: Estrutura de uma página

O index.html cria uma página com o título Olá, mundo! e um parágrafo de apresentação.

O DOCTYPE informa que o documento usa HTML moderno. A tag html envolve a página, e lang="pt-BR" indica que o conteúdo está em português do Brasil.

O head reúne as informações sobre a página. O charset UTF-8 permite mostrar acentos corretamente. A configuração viewport ajusta a área de visualização à largura do aparelho. O title define o nome que aparece na aba do navegador.

O body contém o que aparece na página. Dentro dele, h1 representa o título principal e p representa o parágrafo.
