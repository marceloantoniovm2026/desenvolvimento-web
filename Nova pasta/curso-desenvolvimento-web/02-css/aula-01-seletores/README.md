Aula 01: Seletores

O index.html contém um título e dois parágrafos. A tag link carrega o style.css, que define a aparência desses elementos.

No CSS, o seletor body aplica a fonte Arial, a cor do texto e uma margem à página. O seletor p aumenta o espaço entre as linhas dos parágrafos com line-height.

A classe destaque aparece apenas no segundo parágrafo. No CSS, o ponto em .destaque indica um seletor de classe. Essa regra coloca um fundo amarelo e um espaço interno no elemento. O padding cria esse espaço entre o texto e as bordas da área.

A unidade rem usa o tamanho da fonte do elemento raiz como referência para as medidas.
