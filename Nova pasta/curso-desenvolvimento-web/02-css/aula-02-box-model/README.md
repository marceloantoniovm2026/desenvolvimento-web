Aula 02: Modelo de caixa

O index.html tem um main com a classe caixa, contendo um título e um parágrafo. O style.css organiza essa área como uma caixa centralizada.

O seletor * aplica box-sizing: border-box a todos os elementos. Com isso, a largura definida inclui o preenchimento interno e a borda. A regra do body retira a margem padrão e define uma fonte sem serifa.

A classe caixa ocupa 90% da largura disponível, mas não passa de 600 pixels. O margin: 2rem auto cria espaço acima e abaixo e distribui igualmente as margens laterais, centralizando a caixa.

O padding afasta o conteúdo da borda. O border desenha a borda azul, e o background define o fundo claro. A margem fica do lado de fora da caixa; o padding fica do lado de dentro.
